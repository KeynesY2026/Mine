# Sound effect sources

These clips are bundled locally so gameplay does not depend on a network connection.

- `bomb-explosion.mp3` — “Deep Boom” by Za-Games, Freesound sound 539968: <https://freesound.org/people/Za-Games/sounds/539968/>. The Freesound page lists it under Creative Commons 0 (CC0 1.0). Original duration: 3.186 seconds. Used for a deliberate bomb attack.
- `mine-hit.mp3` — “Short Explosion.wav” by animationIsaac, Freesound sound 207322: <https://freesound.org/people/animationIsaac/sounds/207322/>. The Freesound page lists it under Creative Commons 0 (CC0 1.0). Original duration: 1.427 seconds. Played at 1.55× speed for a brisk mine-hit cue.

The included MP3s are Freesound preview encodings of the CC0 works. They are provided for game playback and can be replaced with higher-quality CC0 files without changing the event wiring.
